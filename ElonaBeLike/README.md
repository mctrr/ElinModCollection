# Elona Be Like

野外行动整合包：队伍指令、视野共享、踢树采集。

## 小地图指令

右键小地图格子，弹出指令菜单：

- 全部去守住
- 全部在此巡逻
- 部分驻守（当前队伍非玩家成员）
- 部分巡逻
- 召回全部
- 部分召回（正在守住或巡逻的成员）

守住中的队友会走到目标格，附近有敌人会打，打完走回该格。玩家走开他们不跟随。换区后守住取消并恢复跟随。

巡逻是两点往返：在**下达命令时你所在的格子**与**右键选中的格子**之间来回走，中途遇敌照打，打完继续巡逻。两个端点在命令下达时就固定，之后你走开不会改变路线。

被命令的队友（守住或巡逻中）与敌人交战时，玩家会获得**战略**技能经验，数值与节奏照搬原版自动战斗（`GoalCombat.Run` 里自动战斗每回合给 PC 的 `ModExp(135, 20)`）。同一回合无论有几个队友在打，玩家只结算一次；玩家自己开着自动战斗时不重复结算。

右键可以点**未探索的区域**（派队友去探图）；左键仍按原版限制，只能走已经探索过的格子。中键仍是原版小地图设置。

## 视野共享

PC 自动获得所有队友的视野，**不需要专长，也不需要道具**：队伍成员（`pc.party.members` 里非 PC 的成员）走到哪，PC 的迷雾就揭到哪，**站在他视野里的敌人也会正常画出来**。

每个队友的共享范围：

```
Clamp(1 + PC 战略等级 / 20, 2, 该队友自身视野)
```

即战略每 20 级 +1 格，下限 2 格（5×5），上限不超过该队友自己的视野半径（非 PC 约 6 格）。

原版队友在白天室外 `GetLightRadius()` 直接返回 0（`Card.cs:6944`），连 Fov 都不建、身周一片黑，所以这里给队伍成员的 `GetLightRadius` 兜了个下限：队友自己那份 Fov 就会把周围照亮。光照的加/减全部交给原版 Fov，我们一行账都不用记。

敌人画不画由 `Player.CanSee` 决定（`BaseTileMap` 里 `!EMono.player.CanSee(chara)` 就 `continue`），那个判定还要求 `cell.pcSync`，而 `pcSync` 是 PC 自己 Fov 的产物 —— 所以队友的 Fov 保持 `isPC=false` 完全不碰它，改用 `Player.CanSee` 的 postfix：站在队友视野格里的角色直接判为可见。

## 踢树

鼠标指着树时：

- **中键**（原版「全部动作」菜单）里多一条「踢」，和原版动作并排；
- **R 键**直接打开同一个菜单。

结算（每棵树只生效一次，用 `Cell.isHarvested` 记账，原版会写进存档）：

- **果树**（`harvestTile != 0`）：掉成熟果实。果实没熟就只播踢的动作，什么也不给 —— 也不会把果树的采集位提前占掉。
- **普通树**：40% 叶子 / 40% 树枝 / 20% 波球。波球就是原版 `GrowSystemTree.OnHitFail` 里那只 `putty`，台词沿用 `mobFromTree`。

只能踢成熟的树，幼苗不给东西。

叶子和树枝**落在树周围 8 格里随机一个空格**，不会直接进背包，也不会一踩就被自动收走（要自己点地上那件东西拾取）。周围全被挡住时才落回玩家脚下。

## 配置

显示队友 / 显示敌人走的是**原版内置的 Mod 配置界面**（ModdingKit 的 `ModConfig`），在游戏的 Mod 列表里选中本 Mod 即可看到，改动会立即写回 `BepInEx\config\elonabelike.elonabelike.cfg`。

`Debug` 下的 `VerboseLog` 默认关闭。打开后日志里才会出现踢树落点、掷骰结果这类逐步细节；平时只留一行加载信息，不刷屏。
